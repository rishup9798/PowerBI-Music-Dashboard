
# 🎵 Spotify Music Analytics Dashboard

A professional **Spotify Music Analytics Dashboard** developed in **Microsoft Power BI** to transform collected and organized music data into meaningful, interactive insights.

The dashboard provides an analytical view of **artists, tracks, albums, genres, popularity, and music trends**, with a focus on clear data storytelling and intuitive visualization.

## 📊 Project Overview

This project involved **collecting, organizing, cleaning, and analyzing Spotify music data** before transforming it into an interactive Power BI dashboard.

The goal was to convert raw music data into a structured analytical solution that makes key patterns, performance indicators, and trends easier to explore and interpret.

## ✨ Key Features

* 🎤 Artist and track analysis
* 🎶 Music popularity analysis
* 💿 Album-level insights
* 📈 Music trends and performance patterns
* 🎧 Interactive Power BI visualizations
* 🔎 Dynamic filtering and slicers
* 📊 KPI-based analysis
* 🎨 Clean, professional, and user-focused dashboard design

## 🛠️ Tools & Technologies

* **Microsoft Power BI**
* **Power Query** — Data cleaning and transformation
* **DAX** — Measures and analytical calculations
* **Data Modeling** — Structuring relationships between datasets
* **Data Visualization** — Interactive charts, KPIs, and filters
* **Spotify Music Data** — Collected and organized for analysis

The objective was to apply an end-to-end **data analytics workflow**, from data collection and preparation to modeling, analysis, and visualization.

It demonstrates how raw data can be **structured, transformed, modeled, and presented visually** to support effective data-driven analysis.
